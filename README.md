# ☕ Coffee Website

A modern and responsive coffee shop landing page built using HTML, CSS, and JavaScript. The website showcases a clean design, smooth user experience, and attractive sections to highlight coffee products and services.

## 🚀 Live Demo

https://coffee-website-five-mu.vercel.app/

## 📖 About The Project

This project is a simple front-end landing page designed for a coffee business. It focuses on responsive design, modern UI practices, and interactive user experience using only vanilla web technologies.

## ✨ Features

* Responsive design
* Modern and clean user interface
* Smooth navigation
* Interactive elements with JavaScript
* Mobile-friendly layout
* Contact and information sections

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

## 🎯 Purpose

This project was created to practice front-end development fundamentals and build a visually appealing landing page using core web technologies.
